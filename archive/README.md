# Archive

`original-anurag-archive.zip` (279 KB) preserves the original project this
template was generalized from ("Anurag University Memories"), as it existed
before reorganization.

Contents of the zip:

- `source/` — pristine application source (FastAPI backend + React frontend,
  Docker/Caddy configs, docs). No `node_modules`, venv, `dist`, or databases.
- `specs/` — the original product specs (`01_Product_Vision.md`,
  `02_UI_UX_Specification.md`, `03_Master_Prompt.md`).
- `prototypes/` — the original single-file HTML scrapbook prototypes plus
  their texture images.
- `README.txt` — manifest with the preservation date.

It is kept here for history only — the living template is everything else
in this repository.
